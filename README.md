# CreaBnB

Portable releases for the CreaBnB desktop app (Make become).

## Install (macOS)

```bash
curl -fsSL https://make-become.github.io/creabnb/install-macos.sh | bash
```

Installs `CreaBnB.app` into **/Applications** (or `~/Applications` if needed) and opens it.

## Other platforms

Download binaries from [Releases](https://github.com/make-become/creabnb/releases).
